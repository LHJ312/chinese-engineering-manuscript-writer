# Conclusion — Runtime Playbook

状态：当前人工辅助V1运行视图。仅整理入口、历史状态与引用，不新增功能或改写规则。案例按需从[精简索引](../examples/case_index.json)选择；无需为本任务加载其他章节。

## 1. SECTION PURPOSE

交付读者可独立理解的研究认识：发现了哪种关系、机制解释到哪一步、方法具有什么已验证能力、工程判断在哪些条件下成立。结论不承担首次论证，不能靠删除上下文扩大命题。


## 2. INPUT REQUIREMENTS

输入包括引言研究问题、正文已支持命题及位置、关键条件/转折/离散或指标分歧、方法能力及验证范围、已有局限。为每项结论建立正文映射。正文没有的排序、阈值、因果、工程建议不得在这里首次出现。

没有正文支撑的位置标NOT_READY或CONTEXT_REQUIRED，留在规划记录；不输出一条看似成熟的新结论。结论可重组多项认识，但形成新增综合命题前应先由作者确认并在正文论证。


## 3. FUNCTION TAXONOMY

| 功能 | 输出认识 | 需保留的边界 |
|---|---|---|
| PRIMARY_FINDING | 直接回应研究问题的主要发现/方法能力 | 对象、比较范围与实际支持指标 |
| PARAMETER_RELATION | 方向、分段、趋缓、交互或取舍 | 转折、条件分支及评价指标 |
| MECHANISM_FINDING | 正文已有机制的凝练联系 | 候选/确定程度、机制适用条件 |
| ENGINEERING_IMPLICATION | 正文已建立的设计或评价含义 | 设计对象、目标、适用范围 |
| BOUNDARY | 约束可脱离正文阅读的结论 | 实质性限制，避免无效免责声明 |
| FUTURE_WORK | 由当前未解问题导出的既有研究方向 | 可选；不能用愿望替代结论 |



## 4. INFORMATION SEQUENCE

主问题答案→关键参数/机制→已支持能力或工程含义→必要边界，是可选顺序。若方法本身为贡献，可先方法能力后发现；若核心是指标冲突，先写冲突及条件。引导句可集中共用对象/范围，但单条脱离上下文会误解时再次写必要条件。

不规定三条、四条或每条“结果＋机制＋意义”。平行条目可用于比较不同参数或对象，不为防AI而强行变换句式和术语。


## 5. PARAGRAPH FUNCTIONS

每条保留一项可复述的主要认识；允许同一取舍下两个指标、同一机制下两个条件分支。用已有核心关系替代研究过程，只删除无认知增量的“开展了/分析了”。新模型、新方法本身是研究贡献时，可以写其提出，并交代其已支持能力和限制。

建立每条结论的“不可丢信息”：主谓对象、比较基准、响应方向、改变该方向的条件、判断强度、必要量级。任何压缩若改变这些信息，都不是单纯语言精简。


## 6. INTERNAL ARGUMENT PATTERNS

- 主要发现：对象/条件→已有关系→必要关键量值。
- 参数取舍：控制条件→指标甲关系→指标乙不同关系；不强制选唯一最优。
- 机制提炼：正文建立的过程联系→解释的响应→不可脱离的边界。
- 方法贡献：提出的实际能力→比较对象/指标→局限，不从一个吻合指标推广全部响应。
- 工程含义：正文建议→适用对象/参数区间→约束条件。

数字按认识用途保留，而非把每张图的数字都抄入条目。M04-P034多个部件比例各有贡献分担用途，不能按数字数量判错；可读性压缩属于可选编辑。M09-P041的两个荷载峰值与平台强度承担量级和约束用途，不能仅因数值多删除。


## 7. RESEARCH-TYPE VARIANTS

纯试验突出已观测模式、组间关系及个体/样本范围；纯数值突出已研究工况、已有验证指标及参数规律；试验＋数值说明共同支持的认识并分清仅模拟得到的机制；理论＋数值说明表达式能力及假设/加载阶段。各路径均不把“完成研究”当作唯一结论。

参数型研究保留收益趋缓、非单调或指标不一致；动力研究区分峰值、全程量与残余响应，不能用泛称“性能”覆盖所有指标。


## 8. CROSS-SECTION CONNECTIONS

从claim_chain_index按研究问题收集Results和Discussion已回答内容，再确认Conclusion没有超出它们。正文链为PARTIAL时，结论不能自动补齐。

M03-P043的整体“较高精度”应回到M03-P039的位移/加速度差异；M05-P029需保留M05-P020已写出的局部反向。M02-P033把材料配比和强度条件带入结论，有助于控制脱离语境后的范围。M10-P036的样本和环境边界可以在结尾集中出现。


## 9. FAILURE MODES

1. **方法流程复述**：只说建立、试验、分析，没有已支持能力或关系；方法为贡献时不禁用这些词。
2. **Results逐条缩写**：条目数量跟着图表数走；改按研究问题归并，数字保留用途。
3. **首次提出新命题**：新增排序、阈值、机制或建议；先返回正文，不能直接润色保留。
4. **压缩丢转折/指标边界**：总体趋势掩盖局部反向，位移精度扩成全部动力响应准确。
5. **工程外推过度**：特定桥梁/构件/试件组合写成普遍设计准则；对照原有范围。
6. **数字或平行形式被机械处理**：不按数量删数字，不为句式变化打乱可比较条目。


## 12. DRAFTING PROTOCOL

1. 按引言问题列已有答案，从正文收集支撑位置。
2. 将重复答案合并，区别主认识与支持数字，保留不同条件或指标的分支。
3. 对每个拟写命题检查范围、强度、基准、阈值与机制是否已在正文成立。
4. 输出Plan：结论功能、凝练命题、正文锚点、必留条件/数字、可合并项、未就绪项。
5. 只把就绪命题写成结论；方法贡献需写能力及验证范围，不抹去其贡献。
6. 脱离正文单独读每条：检查是否误报全程单调、全指标改进、全局最优或普遍适用。
7. 检查相邻条目有无同义复述；必要平行结构保留。

将“可直接复述的局部观察”和“尚需确认适用对象的外推”拆为两个Plan项目。能从正文直接看出同口径转折遗漏时可判需修；工程推广是否成立若需新增科学论证，则只标范围待确认，不自动判其研究结论错误。
