# Results — Runtime Playbook

状态：当前人工辅助V1运行视图。仅整理入口、历史状态与引用，不新增功能或改写规则。案例按需从[精简索引](../examples/case_index.json)选择；无需为本任务加载其他章节。

## 1. SECTION PURPOSE

回答发生了什么、对象间如何不同、响应在哪些条件下改变。读者应能把每项判断对应到方法定义的指标及实际图表。结果组织以问题和响应关系为线索，可保留损伤演化的真实时间顺序。


## 2. INPUT REQUIREMENTS

输入需含作者确认的发现、工况/对照、指标定义、图表、比较基准、必要转折/异常与离散性、已建立的局部解释。只有原始数值而没有关系判断时，Plan可提出待回答的比较问题，不擅自把计算清单转成新科学结论。

把观测、计算定义、作者解释、未决原因分开。未经输入给出的阈值、显著性、全局最优及统计稳定性不由润色生成。


## 3. FUNCTION TAXONOMY

| 功能 | 判断对象 | 常见混淆 |
|---|---|---|
| OVERALL_RESPONSE | 全程/组别的主要响应形态 | 以研究工作总结代替发现 |
| COMPARISON | 同口径下对象或指标的关系 | 单指标排序被写成综合优越 |
| PARAMETER_EFFECT | 参数与响应的已有关系 | 工况逐项播报，没有关系 |
| SPATIAL_FIELD | 指定阶段、变量与位置的分布/迁移 | 颜色深浅替代物理量 |
| FAILURE_MODE | 破坏形态、部位、顺序及组间差别 | 单件现象变全组规律 |
| TIME_HISTORY | 阶段、起效时间、峰值与残余 | 只比峰值抹掉历程 |
| VALIDATION_RESULT | 指定指标、阶段的吻合和偏差 | 一个比值变全面准确 |
| NONMONOTONIC_RESULT | 反向区间、转折、平台或收益趋缓 | 只保留首尾点 |
| ANOMALY | 偏离已建立参照的响应 | 把未知原因直接说成错误数据 |
| MODEL_COMPARISON | 模型/理论/试验在同量同阶段的对照 | 不同误差分母相互比较 |

ANOMALY无需是主标签才能记录：异常可作为参数段中的次功能；不为凑词表而寻找坏数据。


## 4. INFORMATION SEQUENCE

按问题选择：总体形态→分组比较→局部差异；时间阶段→关键事件→峰值/残余；模式分类→模式内参数关系→跨模式例外；验证结果→适用指标→模型扩展结果。顺序不固定，异常若改变全段认识可先写异常。

若两个指标给出不同排序，先建立各自口径，再并列差异；不强行收束成唯一“最好方案”。多组数据可在图表集中呈现，正文按同一判断组织，而不是按每条曲线各写一段。


## 5. PARAGRAPH FUNCTIONS

结果段通常承担比较判断、阶段描述、参数关系、空间关系、模式差别或验证范围中的一项主任务；必要时带异常、条件或就近解释。一个中心问题可以容纳多个变量和指标，条件分支只要共同改变中心判断就不强拆。

每段规划四项：本段回答的比较问题、保留的数据及用途、图表定位、解释层级。判断可前置，也可在异常和对照之后归纳；不把“图X表明”当禁词。M01-P018的比较判断后置仍有可追踪依据。


## 6. INTERNAL ARGUMENT PATTERNS

**图文分工。** 正文提取关系、异常、转折和读取方法，图表保留完整组别。首次出现复杂坐标、相位、分区或读图口径时可先导读。云图至少给变量、位置、阶段和共同显示/比较条件，再写空间变化；没有这些输入就不以颜色推出传力机制。

空间关系可复用P4-DIS-06的沿程轴力分担及M09-P035的沿传播距离应力/应变关系：正文先讲物理量与位置，再联系已有解释。本轮未建立不同色标导致误读的完整正反配对，因此不把这一检查的全部区分能力宣称已验证。

**数字保留尺度。** 逐个数字分配用途：定义口径、量级、对照、极值、转折、异常、离散性、边界。没有用途才考虑交给图表；不存在每段最多几个数的配额。先问压缩会不会误报单调、同向、无异常，再问能否减数字。M04-P010的均值与离散系数不能因数字多删除；M08-P020的模式转换对照不能只留首尾值。

**参数模式。** 保持量与比较范围→方向/分段关系→关键对照→反例或指标取舍。M05-P020保留芯层厚度超过某取值后的局部反向；M10-P027的薄肋板/大孔组合是总体关系的条件分支。若参数联动，应称联动设计响应，不假装单因素敏感性。

**解释层级。** OBSERVATION是直接报告已展示关系；PROXIMAL_INTERPRETATION只调用已建立的定义、阶段、模型假设或局部过程，帮助读图；MECHANISTIC_INTERPRETATION要论证内部状态、竞争原因或跨结果意义。多指标比较本身仍可属于观察，多证据也不自动等于机制。具体判别调用[Discussion §6](discussion.md)。


## 7. RESEARCH-TYPE VARIANTS

- 纯试验：按组别/个体层级报告破坏、曲线和必要离散；不得虚构重复试验。
- 纯数值：验证支持范围与参数发现分开；云图比较阶段一致，拟合关系不能自动成为机制证明。
- 试验＋数值：先分清实测现象与模型补充的不可测响应；同指标对照后再写扩展，未扩展的不补扩展。
- 理论＋数值：解析预测、FE结果和既有试验各自承担不同对照；误差可能随加载阶段变化，保留该条件。
- 动力：峰值、持续时间、均方根、位移/能量及空间位置按当前问题取用，不强制全部输出。


## 8. CROSS-SECTION CONNECTIONS

每项Results判断连接Methods中的指标定义、输入组别及图表。M02的速度/平台值定义支撑四阶段描述；M03位移对比不能代替加速度验证。结果缺少的工程含义留给Discussion，不能因期望闭环而临时补出。

把候选解释送入Discussion时保留结果锚点及其适用条件；合章允许连续写观察—解释，但不能把层级抹平。结论提炼时保留这里改变趋势的例外。


## 9. FAILURE MODES

- 把所有曲线依次读一遍：先定位已确认的比较判断，再选择数字。
- 只写首尾值：检查中间转折、异常模式和离散性是否改变判断。
- 颜色朗读：返回变量、位置、阶段；没有确认的物理关系就只描述观察。
- 同步变化直接升级因果：保留原确定性，转入解释任务而非换因果动词。
- 作者动作重复Methods：只有处理/分组定义影响读图时保留。
- 插入网格、记录完整性等共性审查打断局部发现：区分必要验证条件与编辑状态，不能把真实限制一起删除。


## 12. DRAFTING PROTOCOL

1. 按问题列发现，连接Methods指标及图表；不把新推导当润色。
2. 选择总体、阶段、比较、参数或空间路径，允许异常先行。
3. 给数字标用途；删除候选需通过转折、离散、量级与范围不丢失检查。
4. 标出观察、定义、就近解释与机制分支；缺前提标CONTEXT_REQUIRED。
5. 输出Plan：主问题、结果锚点、保留数字、条件/例外、图表、解释去向、读者应记住的关系。
6. 依Plan写草稿，不强制每段补机制和意义；回看相邻段是否重复播报。

跨段比较前可用一行对齐表：对象/组别、载荷组合、响应分量、阶段、基准、数值来源。若某列不同，不直接判方向矛盾；若原文/图表仍不能恢复，标CONTEXT_REQUIRED，不选一个方向覆盖其他来源。这是C-03/I-01/L-01在复合受力比较中的实施。


## 13. CHECKLIST

- [ ] 指标、基准、阶段和对象可辨认。
- [ ] 关键转折、反例、离散性和未见一致趋势均保留。
- [ ] 数字有用途，不以数量或百分比密度直接删数。
- [ ] 云图文字去掉颜色后仍有物理观察。
- [ ] 参数小节已有关系判断，局部无总结句不等于全节无认识。
- [ ] 局部解释有已建立前提；机制及设计分支有明确功能位置。
- [ ] 单指标改善没有被写成综合最优；无需为保留条件而句句加免责声明。
