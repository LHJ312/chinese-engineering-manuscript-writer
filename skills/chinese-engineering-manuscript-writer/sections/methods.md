# Methods — Runtime Playbook

状态：当前人工辅助V1运行视图。仅整理入口、历史状态与引用，不新增功能或改写规则。案例按需从[精简索引](../examples/case_index.json)选择；无需为本任务加载其他章节。

## 1. SECTION PURPOSE

使读者明确：研究比较什么、对象如何定义、响应如何产生与取得、哪些假设限定后续解释。Methods为引言问题提供可实施的回答路径，并为Results指标建立口径。不能用软件名代替模型，也不能把档案核查过程当作研究设计。


## 2. INPUT REQUIREMENTS

输入至少包含研究问题、对象/组别、保持量与变化量、几何与材料、边界和加载、测量/输出定义，以及已确认的处理方式。数值研究另需理想化、本构、相互作用、离散与求解设置、现有验证对象；理论研究另需假设、符号、推导关系和比较对象。

每项输入标为已有、由图表可恢复、当前缺失、不适用。缺失项留在Plan的作者问题栏；不填默认摩擦系数、样本量或质量缩放设置，不仅删除未知提示就交付看似完整的正文。论文输入与写作元数据分开，正文不输出核验状态。


## 3. FUNCTION TAXONOMY

| 功能 | 进入条件与主要输出 |
|---|---|
| OBJECT | 首次定义研究系统、组成与比较对象 |
| MATERIAL | 给出实测或采用的材料性质及来源，不混淆两者 |
| SPECIMEN_OR_GEOMETRY | 建立共同构造、尺寸、分组差异及命名 |
| EXPERIMENTAL_DESIGN | 说明用哪些对照区分哪个因素，报告实际组别与数量 |
| NUMERICAL_MODEL | 说明实物如何理想化及各部件如何连接 |
| CONSTITUTIVE_MODEL | 本构、失效准则、参数来源及必要假设 |
| BOUNDARY_LOADING | 约束、加载位置/方向/历程及控制条件 |
| MESH | 单元、局部加密、选取依据及实际检验量 |
| VALIDATION | 定义比较对象、指标、阶段与判定方式；不预先宣称全面可靠 |
| PARAMETER_DESIGN | 基准工况、变化范围、保持量及联动变化 |
| MEASUREMENT | 物理量、位置、方向、仪器/采样/处理之间的对应 |
| OUTPUT_METRIC | 指标定义、提取时刻/区域、基准与符号 |
| PROCEDURE | 对制作、路径依赖加载或算法状态有影响的执行顺序 |
| ANALYTICAL_DERIVATION | 沿用语料索引标签；由假设、平衡或本构导出实际使用的表达式 |

110是语料中Methods所在章节的单元数，不是以上标签的全部案例数。验证、指标定义、解析推导也可能分布在结果相关章节。


## 4. INFORMATION SEQUENCE

先列输入依赖，再选择编排。一般是对象与比较设计→必要材料/构造→边界与加载→测量或计算→输出与验证。材料参数若决定模型定义，应前置；同一对象的多个用途可同段。量测定义可以紧邻第一次结果读图，不因章节纯度强制搬走。

两条不可混淆的顺序：作者工作日程没有当然的正文地位；工艺、加载历史和状态更新若改变结果，其时序就是方法内容。M02-P009的分层制作与M03-P035的碰撞判定—更新—积分均应保留。


## 5. PARAGRAPH FUNCTIONS

| 段落任务 | 内部信息组织 | 结束时可回答的问题 |
|---|---|---|
| 定义共同对象与变化量 | 共同构造→对照差别→设计用途；尺寸表承载完整清单 | 哪项变化回答引言中的哪一问？ |
| 材料或本构说明 | 对象→采用关系/实测性质→参数来源→特殊假设 | 哪些是试验值，哪些是采用值？ |
| 装置与测量 | 加载/约束→被测量→位置与处理；可用表图建立对应 | 读者能否恢复量、对象、位置、方向？ |
| 数值理想化 | 实物关系→数值表示→保留/忽略内容→作用范围 | 哪种响应可能受该假设影响？ |
| 指标与验证设计 | 指标口径→参照→比较阶段；结果只留选法所需部分 | 后文的误差究竟比较什么？ |
| 必要流程 | 初态→条件判断→操作/更新→终止或下一步 | 调换步骤会改变构造或计算状态吗？ |

一段多种标签不等于失序。只有无说明依赖的插入打断当前任务、或设置尚未交代便使用其输出时，才建议分层。不要把“所有参数都真实”当成无需组织的理由。


## 6. INTERNAL ARGUMENT PATTERNS

可选模式：设计目的—共同构造—控制变量；物理对象—理想化—输入—输出；假设—推导—表达式适用条件；执行状态—分支—更新—终止。它们是信息槽位，不是固定句式，已有图表能恢复的信息不强制再写一句。

RULE-GAP-CANDIDATE-M01（区别于既有M-01）的本章执行释义：**优先按说明功能和信息依赖组织；只有制作、加载或算法次序本身影响复现时，才以时间顺序为主线。** M05-P008虽长，但依次建立几何、网格、接触和载荷；可分层改善检索，不能仅凭长度判BAD。M07-P009把控制转换和测量并列，仍有清楚用途。

METHODS-IMPL-01已作为E-01的Methods实施原则确认，不计独立横向规则。真实坏例BAD-02检出的是功能与档案状态交错，不是时间顺序本身。


## 7. RESEARCH-TYPE VARIANTS

| 路径 | 推荐依赖顺序 | 实际来源与限制 |
|---|---|---|
| A 纯试验 | 对象/对照→制作与材料→加载/量测→指标/处理 | M02、M07；公式计算不自动把论文改成试验＋数值 |
| B 纯数值 | 物理问题→理想化与参数来源→边界/离散/求解→已有验证→参数组与输出 | M04、M05、M06；M06无独立验证记录，不得补造 |
| C 试验＋数值 | 共同问题→试验设计及测量→相应模型→比较指标→模型承担的额外任务 | M01、M09、M10；M08实际以验证/失效解释为主，不强加数值扩展 |
| D 理论＋数值 | 假设与符号→解析关系→FE对象与输入→既有试验检验FE→解析/FE同口径比较 | 建模依据M04-P025及M10-P028的解析功能与数值链；区分既有试验来源，不要求把数值研究写成新增试验 |

参数研究叠加于上述路径：单因素需写保持量；联动设计需写联动关系，不能为了整齐称为“其余完全相同”。动力研究增加历程、触发、同步和数值输出时刻；静力研究按实际加载控制与终止条件展开。


## 8. CROSS-SECTION CONNECTIONS

Plan给每个研究问题连接一个方法响应、一个输出指标和一个比较基础。M10-CC01的端部承压问题由有/无承压构造回应；M09-CC01由试验观察限制引出数值传播分析。M06的全桥内力传入局部模型是加载输入，不是验证证据。

Methods定义结果的对象与量，Results报告实际比较，Discussion解释差异及假设影响，Conclusion只能概括已成立能力。若链条缺项，记录缺项，不能写成完整闭环。


## 9. FAILURE MODES

- 软件菜单/日程取代设置：删除无信息操作，保留影响状态的顺序（E-01）。
- 配置、指标和记录缺口交错：先区分科学条件与编辑未知，再依赖分组；不能删除未知后假装已知（METHODS-IMPL-01、L-02）。
- 型号堆积而量测关系不可恢复：先读表图；仅当仍无法确定对象/量/位置/处理才补问（N-01）。
- 从网格稳定或单个峰值吻合写成全面准确：写明实际支持指标和阶段（M-02）。
- 把论文研究范式强塞成统一链：不把既有试验当本研究试验，不把拟合公式当有限元，不补数值参数扩展。


## 12. DRAFTING PROTOCOL

1. 提取研究问题及实际研究类型；缺失条件留作者问题栏。
2. 建立“对象—变化/保持量—加载—量测/计算—输出”的对应表。
3. 标出先决条件，优先完成依赖，再安排段落；允许必要时间顺序。
4. 为每段给出目的、必留设置、表图位置、相邻依赖、可删内容；不先套句子模板。
5. 仅用已确认输入写草稿；参数清单与正文分工，保留特殊实现。
6. 检查输出口径和后文验证是否一致；把不能恢复的信息列为问题，不重做研究。

Plan输出字段：段落任务、输入ID、必须保留的信息、表图/公式、前后依赖、研究类型例外、作者待答项。该字段表用于规划，不要求出现在论文正文。

若输入含控制切换或协同执行，增加一张可选依赖表：阶段、受控输入、该阶段保持关系、切换触发、更新操作、终止条件。跨阶段不默认保持量相同：力比和位移比分别记录；控制转换、状态判断和更新按阶段依赖保留。理论＋数值路径按假设→解析→FE验证链交叉对应，不能把引用试验改写为本研究试验。
