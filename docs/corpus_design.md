# 核心语料设计

内部核心语料冻结规模为15篇：MODEL=10、DEV=3、HOLDOUT=2。已有三篇因被多轮分析，固定归入MODEL，没有再作为DEV或HOLDOUT。新增来源用于降低冲击梁与试验数值结合研究的集中偏置。

选择覆盖试验、数值、试验＋数值、理论＋数值，以及参数和机制分析；兼顾非冲击、静力/准静态、动力、多指标与梁以外对象。正式发表仅代表高质量候选来源，不自动把每个段落标成GOOD。讨论功能按机制、参数原因、多结果解释、理论比较及边界识别，不要求独立“讨论”标题。

MODEL用于模式形成，DEV用于章节闭环与泛化走查，HOLDOUT仅用于最终独立任务测试。H14为覆冰导线，H15为藏式木梁柱节点。其原文不进入本公开包的案例、Style Card、规则或Playbook。

本包只公开运行案例用到的MODEL书目信息与必要外部页码/栏位定位，见[公开来源书目](../skills/chinese-engineering-manuscript-writer/examples/sources.md)。不复制开发期候选清单、筛选矩阵、PDF、HTML全文或内部原文段落索引。

14张Style Cards按写作动作组织。M02、M04、M09、M10是内部选定的风格参照来源，但该身份不表示其全部段落均值得模仿，更不授权移植论文事实。24个公开案例记录仅为编辑模式摘要；内部未公开稿件及其身份、参数与改稿已移除。受控案例摘要明确与真实论文原段区分。

核心库不因遇到“可能更好”的论文而扩充。版本后续问题只有呈现重复性、跨论文的模式时，才可累计进入后续版本讨论；本次发布不扩库。
